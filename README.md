# 🎮 Flutter Tic Tac Toe

A simple, modern **Tic Tac Toe** game built using **Flutter**.  
---

## 🧩 Features

- 🎨 Clean and responsive UI  
- ✖️🟢 Player 1 (X) vs Player 2 (O)  
- 🏆 Winner detection and draw handling  
- 🔁 Restart game after each round
